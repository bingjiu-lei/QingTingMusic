晴听音乐不堆推荐、不塞资讯，打开就是你的音乐。想听什么直接搜，自己的收藏、歌单、专辑、歌手都在手边。

它更适合已经知道自己想听什么的人，而不是在首页推荐里不断寻找内容。

> 当前仍是早期测试版本，功能和界面会继续调整。

## 为什么用它

- **简洁不打扰**：只有“我的音乐、搜索、设置”三个入口，没有信息流和广告。
- **搜索优先**：单曲、歌手、专辑都能直接搜到。
- **个人音乐库完整**：收藏歌曲、创建和收藏歌单、专辑、关注歌手、云盘、最近播放都在一个地方。
- **再次播放更快**：听过的歌会缓存在本地，再次播放不用重新加载。
- **深浅色模式**：跟随你的喜好切换。

## 下载与安装

前往 [Releases](https://github.com/bingjiu-lei/QingTingMusic/releases/latest) 下载最新的 Windows 安装包：

```text
QingTingMusic-Setup-v版本号-x64.exe
```

双击安装后，可以从开始菜单或桌面快捷方式打开晴听音乐。

支持 Windows 10 和 Windows 11 64 位系统。

> 安装包暂未进行数字签名。如果 Windows SmartScreen 显示安全提示，可以点击“更多信息”，再选择“仍要运行”。

## 主要功能

- 酷狗账号二维码登录
- 搜索单曲、歌手和专辑
- 在线播放、暂停、切歌和自动播放下一首
- 收藏歌曲、创建歌单和收藏歌单
- 查看收藏专辑、关注歌手、云盘和最近播放
- 从歌曲进入歌手或专辑页面继续浏览
- 浅色与深色模式
- 本地缓存听过的歌，减少重复等待
- 自定义音乐 API 地址

## 使用说明

1. 打开晴听音乐，在左下角登录酷狗账号。
2. 默认音乐接口已经配置，也可以在“设置”中修改。
3. 在“搜索”中输入歌曲、歌手或专辑名称。
4. 播放过的音乐会缓存在本地，方便再次播放。
5. 新版本可以直接覆盖安装，完整卸载会同时清理应用数据。

如果遇到无法登录、搜索缓慢或播放失败，可以先检查“设置”中的 API 地址和当前网络状态。

## 常见问题

**登录后看不到我的歌单或收藏？** 确认登录的账号正确，下拉刷新一次；如果仍为空，检查“设置”中的 API 地址是否可用。

**播放时提示“无版权或需付费”？** 这首歌当前接口无法播放，可以试试搜索同名歌曲的其他版本。

**覆盖安装会丢失数据吗？** 不会。覆盖升级会保留用户数据，完整卸载才会清理。

## 关于这个项目

晴听音乐是一个个人学习与实践项目。

我平时更多是在已有项目中补需求和修复问题，这个项目则是一次从想法、界面、接口、播放，到安装和发布的完整尝试。它不会追求功能最多，而是希望把搜索、个人音乐库和播放这几件事做得直接、舒服、可靠。

项目目前专注于 Windows。Android 版本会在 Windows 体验稳定后再考虑。

# 晴听音乐 v0.9.3

## 主要更新

- **写真模式更稳定**：默认写真壁纸会随窗口完整铺满；写真与专辑封面模式切换更平滑，减少加载时的闪白与跳变。
- **歌单管理补齐**：支持新建、删除自建歌单；默认收藏歌单已受保护，无法误删。
- **播放体验优化**：完善桌面歌词、歌词加载与播放控制的反馈，降低切歌及切换播放页时的打断感。
- **全局界面细化**：加入轻微毛玻璃层次，并统一侧栏、标签、推荐页与播放栏的视觉和交互状态，改善深浅主题一致性。

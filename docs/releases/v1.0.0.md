# 晴听音乐 v1.0.0

> 晴听音乐 v1.0.0 正式版来了，这一版，值得更新。

## 更新内容

- 新增歌曲高潮片段刻度，点击可跳转到对应位置。
- 歌手详情页新增相似歌手。
- 未登录启动时显示登录提示。
- 添加歌曲到歌单时自动去重；移除歌曲前需要确认。
- 每日推荐日期、歌曲列表和专辑卡片适配深浅色主题。

## 问题修复

- 修复中文输入法搜索时输入被打断的问题。
- 修复搜索结果滚动时遮住分类栏的问题。
- 修复全屏播放页进度条不同步的问题。
- 修复歌曲专辑跳转错误、部分歌手头像缺失和歌单同步问题。

## 下载与安装

- 文件：`QingTingMusic-Setup-v1.0.0-x64.exe`
- 系统：Windows 10 / 11（64 位）
- 大小：34,453,422 字节（32.86 MiB）
- SHA-256：`3E39FB3038E4D4BEC25E5BDB5D828BEA6F9D4D92CA7E5EC73239DFEFC8E12C0F`

直接运行安装包即可覆盖旧版本，登录信息、设置、缓存和播放记录会保留。

安装包暂未进行数字签名。若 Windows SmartScreen 提示未知发布者，请确认下载来源后点击“更多信息”→“仍要运行”。完整卸载会删除程序及晴听音乐用户数据。

## 项目说明

晴听音乐是使用 Flutter 开发的 Windows 桌面端个人学习与技术实践项目。音乐、账号及相关数据通过酷狗官方接口获取；请遵守平台规则，尊重音乐版权，仅用于个人学习和技术研究。

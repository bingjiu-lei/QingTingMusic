# 晴听音乐 v0.9.0：界面重构，主题由你，播放更顺

这一版不靠堆功能吸引人，而是把每天都会碰到的界面、搜索、推荐和播放重新做顺。

## 这次值得更新

- **整套 UI 重构**：标题栏、侧栏、内容区和播放器不再横竖硬切，窗口从上到下是一套连续氛围。
- **主题真正可自定义**：浅色、深色、5 组预设颜色和自由取色全部落地，选择什么颜色，界面就呈现什么颜色。
- **推荐更像音乐入口**：每日推荐一键播放或查看完整歌单；私人 FM 按频道与偏好持续换歌，不做杂乱信息流。
- **播放器重新排布**：进度条、收藏、播放模式、专辑、音质、音量和队列各归其位，控制更轻、更准。
- **搜索告别“管理系统感”**：空状态、最近搜索、联想词、清除按钮和分类结果全部重做。
- **随机播放记得上一首**：快速切歌也能沿真实听歌路径返回，不会再随机抽一首冒充“上一首”。

## 详细更新

### 全局界面

- 重做浅色与深色配色、页面背景、卡片层次、圆角、阴影和交互状态。
- 收窄并重新对齐左侧导航，品牌、菜单、账户头像和设置入口更协调。
- 接入真实用户头像；品牌图标可快速切换明暗模式，设置页保留完整外观选项。
- 标签菜单改为轻量文字与短指示线，减少大色块和页面割裂感。
- 统一可点击控件的鼠标指针，普通歌曲行不再错误显示手型。
- 更新 README 与全套界面截图。

### 播放体验

- 重做底部播放器和播放页控制区，按钮保持同一基线，减少抢眼和重复入口。
- 新进度条清晰区分已播放、缓冲和剩余部分，拖动反馈更自然。
- 修复音量浮层漂到内容区的问题，面板始终跟随音量按钮。
- 收藏改为即时反馈，请求失败时自动恢复，减少点击后的迟滞感。
- 多歌手歌曲支持逐个进入歌手主页，不再把整串歌手名称一起搜索。
- 优化播放页打开与关闭时的重绘范围，切换更轻、更稳。

### 推荐与搜索

- 每日推荐改为主视觉入口，支持直接播放和进入完整歌曲列表。
- 私人 FM 展示当前歌曲封面、歌名和歌手，频道与偏好分区更清楚。
- 切换 FM 频道或偏好后重新请求；接近队尾时自动补歌，避免只循环最初几首。
- 搜索首页、最近搜索、联想搜索、清空操作和搜索结果布局统一重做。
- 搜索结果保持单列音乐列表，歌曲、歌单、歌手和专辑分类切换更自然。

## 下载与安装

下载并运行：

```text
QingTingMusic-Setup-v0.9.0-x64.exe
```

支持 Windows 10 和 Windows 11 64 位系统。

已经安装旧版本时，直接运行新安装包即可覆盖升级，无需提前卸载。

> 安装包暂未进行数字签名。如果 Windows SmartScreen 显示提示，请点击“更多信息”，再选择“仍要运行”。

## 升级与卸载

- 已验证从 `v0.8.0` 覆盖升级到 `v0.9.0`，用户数据标记可正常保留。
- 覆盖升级会保留登录信息、设置、本地缓存和播放记录。
- 完整卸载会删除程序和 `D:\QingTingMusic\userdata` 中的晴听音乐用户数据。
- 如需保留本地内容，请在完整卸载前自行备份用户数据目录。

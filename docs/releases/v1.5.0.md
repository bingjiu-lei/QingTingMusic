# 晴听音乐 v1.5.0

## 更新内容

- 推荐页新增“热门歌手”分类浏览。
  - 支持按地区（华语、欧美、日本、韩国）与分类（男歌手、女歌手、乐队组合）筛选。
  - 支持按拼音/英文首字母（全部、A-Z、#）快速检索。
  - 采用歌手卡片网格布局，点击可直接进入歌手主页。
- 重构精选榜单与歌曲预览。
  - 精选榜改为通栏单行 4 首轻量歌曲卡片，支持自适应布局与快捷播放。
  - 新增全量排行榜切换弹窗，可在首页与榜单详情页内自由切换所有官方榜单。
  - 榜单切换支持本地持久化记忆，应用重启或返回主页时自动保持选中状态。
- 新增窗口状态记忆。
  - 退出时自动记录窗口尺寸、屏幕位置及最大化状态，下次启动时精准恢复。
  - 优化桌面端首帧渲染与退出清理流程，启动更平滑。
- 优化推荐页视觉与排布。
  - 推荐页主内容区采用垂直居中自适应布局，改善大窗口模式下的留白平衡。
  - 校正每日推荐封面层叠顺序，确保首曲封面展示于最上层前景。
  - 优化歌曲卡片悬浮动效，保持通透底色质感与柔和微光抬升。
- 统一全局弹窗交互。
  - 登录过期等系统提示弹窗统一接入圆角毛玻璃规范与主题操作按钮。

## 问题修复

- 修复使用快捷键切歌后，按空格键误触发个人账户弹窗的问题。

## 下载与安装

- 文件：`QingTingMusic-Setup-v1.5.0-x64.exe`
- 系统：Windows 10 / 11（64 位）
- 大小：26,338,477 字节（25.12 MB）
- SHA-256：`AA4AEEF0744712A0DBC48A5DF5042967E707D1D7B9BBFE2F6FC7982D95A4FD9C`

直接运行安装包即可覆盖旧版本。覆盖升级会保留登录信息、设置、缓存和播放记录。

安装包暂未进行数字签名。若 Windows SmartScreen 提示未知发布者，请确认下载来源后点击“更多信息”→“仍要运行”。

完整卸载会删除程序、缓存、账号会话和其他晴听音乐用户数据。

## 项目说明

晴听音乐是使用 Flutter 开发的 Windows 桌面端个人学习与技术实践项目。音乐、账号及相关数据通过酷狗官方接口获取；请遵守平台规则，尊重音乐版权，仅用于个人学习和技术研究。

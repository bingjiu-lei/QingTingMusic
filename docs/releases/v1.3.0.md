# 晴听音乐 v1.3.0

## 新增

- 新增MV音源功能（实验性）。
  - 支持搜索MV音源。
  - 支持在歌手详情页查看 MV。
  - 支持“我的音乐”中的 MV 收藏列表。
  - 歌曲没有可用音源时（如收费数字专辑），可自动尝试切换到匹配的 MV 音源。
  - MV 功能默认开启，也可以在设置中关闭。
- 新增歌单双向管理。
  - 可直接查看歌曲是否已加入歌单。
  - 支持从当前歌单移除歌曲。
  - 移除正在播放的歌曲后会自动切换播放。
- 新增全局播放快捷键。
  - 空格键：播放或暂停。
  - Ctrl + 左右方向键：上一首、下一首。
  - Ctrl + 上下方向键：调高、调低音量。

## 优化

- 全面优化播放详情页。
  - 改进封面、歌词和播放控制布局。
  - 优化全屏、大窗口和小窗口下的自适应显示。
  - 增大大屏下的封面和歌词显示区域。
  - 优化歌词高亮、自动滚动和长歌词显示。
  - 修复部分窗口尺寸下内容偏移和暗色闪烁问题。
- 优化云盘歌曲。
  - 每次打开软件时刷新云盘歌曲。
  - 按真实上传时间倒序显示。
  - 改进云盘歌曲与在线歌曲的匹配。
- 优化“我的音乐”。
  - “播放全部”按钮默认隐藏，悬浮到标题区域时显示。
  - 歌单、收藏歌单、专辑、歌手和每日推荐详情页支持手动刷新。
  - 刷新时显示加载状态。
- 优化歌单操作弹窗、播放栏和全屏播放页的收藏状态显示。
- 优化内置图片资源。
  - 默认图片和写真改用 WebP 格式。
  - 减少资源体积，降低安装包大小。
- 优化安装包内容，避免将本地运行产生的用户数据打入安装包。

## 修复

- 修复歌曲从专辑页或搜索页移出歌单时，无法正确识别歌曲的问题。
- 修复云盘关联歌曲无法识别歌单收录状态的问题。
- 修复歌单缓存刷新不及时的问题。
- 修复普通歌词没有逐字时间轴时，播放进度不跟随滚动的问题。
- 修复长歌词滚动、歌词居中和窗口缩放时的排版问题。
- 修复播放详情页播放模式图标与底部播放栏不一致的问题。

## 已知限制

- MV 收藏目前只保存在本地，不会同步到酷狗账号。
- MV 是否可以播放取决于酷狗接口返回的资源、账号权限和版权状态。
- 部分歌曲可能没有可匹配的 MV 音源。
- 付费歌曲或无版权歌曲可能仍然无法播放。

## 项目说明

晴听音乐是使用 Flutter 开发的 Windows 桌面端个人学习与技术实践项目。

音乐、账号及相关数据通过酷狗官方接口获取。请遵守平台规则，尊重音乐版权，仅用于个人学习和技术研究。

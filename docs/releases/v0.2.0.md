# 晴听音乐 v0.2.0

这一版主要解决播放稳定性和音乐库使用体验，同时补齐自动下一首，让日常听歌不再需要频繁手动操作。

## 本次更新

- 新增歌曲播放结束后自动切换下一首。
- 修复部分电脑无法读取音乐缓存、提示没有文件访问权限的问题。
- 遇到不可读取或损坏的旧缓存时，会清理并重新下载。
- 优化创建歌单与收藏歌单的识别和分区展示。
- 收藏专辑与云盘歌曲改为较新的内容优先显示。
- 歌曲列表默认显示序号，鼠标悬浮后再显示播放按钮。
- 优化深色模式切换后设置页面显示异常的问题。
- 优化播放进度条，使轨道更完整、紧凑。
- 更新 README，让项目介绍、安装方式和使用说明更清晰。
- 修正发布验证脚本，测试失败时会正确中止构建流程。

## 下载与安装

下载并运行：

```text
QingTingMusic-Setup-v0.2.0-x64.exe
```

当前支持 Windows 10 和 Windows 11 64 位系统。

安装包暂未进行数字签名。如果 Windows SmartScreen 显示提示，可以点击“更多信息”，再选择“仍要运行”。

## 升级与卸载

- 已安装旧版本时，可以直接运行新安装包覆盖升级。
- 覆盖升级会保留登录信息、设置和本地缓存。
- 从 Windows 应用管理或开始菜单完整卸载时，会删除程序和晴听音乐用户数据。

- 当前仅维护 Windows 桌面版本。

## 项目声明

晴听音乐是个人学习与技术实践项目，不提供或存储音乐资源。音乐、账号及相关数据来自用户配置的第三方 API 服务。请遵守相关平台规则，尊重音乐版权并支持正版内容，请勿用于商业用途或违法行为。

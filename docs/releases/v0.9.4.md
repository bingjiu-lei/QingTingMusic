# 晴听音乐 v0.9.4

## 主要更新

- **搜索页视觉重做**：重新设计搜索页空状态引导，去掉底部快捷键提示；修复夜间模式下文字看不清的问题。
- **标签与菜单统一**：统一全软件各页面标签大小与风格，点击区域更舒适。
- **应用图标圆角化**：任务栏图标四角改为圆弧，视觉更柔和。
- **卡片悬浮更智能**：鼠标悬浮提示仅在文字被省略时才弹出，卡片间移动不再频繁误触发。
- **歌单滚动不遮挡**：修复歌单页面向下滚动时内容遮住顶部菜单栏的问题。
- **超长歌词自动滑动**：歌词超出显示范围时自动向左平滑滚动，完整展示每一句，不再打省略号截断。
- **暂停时双击歌词可跳转**：暂停状态下双击任意一行歌词，会自动恢复播放并跳到对应位置。
- **搜索框聚焦更丝滑**：修复点击搜索框时图标和历史卡片微小抖动的问题，聚焦光晕更柔和。
- **暗黑模式卡片光晕**：夜间模式下卡片顶部光晕改为跟随主题色的淡雅晕染，替代之前灰白色的生硬效果。
- **日夜切换文字过渡**：切换日间/夜间模式时，搜索页文字颜色平滑渐变，不再闪烁跳变。
- **桌面歌词后台同步**：修复程序切到后台时桌面歌词卡住不动的问题，现在始终保持逐字同步。

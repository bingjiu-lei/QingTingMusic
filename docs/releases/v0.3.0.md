## 核心变更：接入酷狗官方 API

本次最大改动是新增 KugouOfficialClient，直接对接酷狗官方接口，不再依赖第三方代理 API。当用户未配置自定义 API 端点时，自动使用官方 API 模式。

- 支持官方搜索、歌曲播放地址解析、歌单/专辑/歌手/云盘数据
- 设备注册、登录二维码、会话管理全部走官方协议
- 内置签名算法（MD5/AES/RSA），无需外部服务

## 新功能

- 播放失败自动恢复：切歌失败时保留上一首歌的播放位置和状态，不会跳到空白界面，错误提示包含具体歌曲名
- 搜索缓存优化：缓存校验封面有效性，避免缓存无封面数据导致界面空白
- 音乐库排序：收藏歌曲、创建歌单、收藏歌单、专辑、歌手、云盘歌曲全部按最新在前排列
- 登录二维码本地生成：接入 qr_flutter，无图片接口时也能生成二维码
- 侧边栏主题切换动画：暗色/亮色模式切换使用 app icon 图片 + 缩放淡入淡出动画
- 专辑封面占位图：替换为本地 album_placeholder.png 图片资源

## 改进

- 播放栏上一首/下一首按钮统一尺寸（42×42），提升点击体验
- 搜索支持更多字段映射（filename、imgurl、albumId 等）
- 歌曲解析自动从"歌手 - 歌名"格式拆分未知歌手

## 新增依赖

- crypto: ^3.0.7 — MD5 签名
- pointycastle: ^4.0.0 — AES/RSA 加解密
- qr_flutter: ^4.1.0 — 二维码本地渲染

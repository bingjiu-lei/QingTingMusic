# 晴听音乐 v1.4.0

## 更新内容

- MV 收藏现与酷狗账号同步，可在“我的音乐”中查看和取消收藏。
- 播放特殊音源或 MV 音源时，可手动转存至个人云盘，并关联酷狗曲库原曲。
- 新增 Windows 后台播放快捷键：`Ctrl + Alt + ← / →` 切歌，`Ctrl + Alt + Space` 播放或暂停；设置页可查看完整说明。

## 下载与安装

- 安装包：`QingTingMusic-Setup-v1.4.0-x64.exe`
- 系统：Windows 10 / 11（64 位）
- 大小：26.32 MB（26,320,985 字节）
- SHA-256：`FFF1B4A82F2945648981D82E5B877A4D0351BD94928380C146B2DC84174C009C`

运行安装包可覆盖升级，登录信息、设置和缓存会保留。完整卸载会删除程序及晴听音乐用户数据。安装包未进行数字签名；如遇 SmartScreen 提示，请先确认下载来源。

## 说明

旧版仅保存在本地的 MV 收藏不会自动同步到酷狗账号。MV 功能现默认显示，原实验开关已移除。音源播放、收藏及云盘转存受资源、账号权限和平台接口状态影响。

晴听音乐是 Windows 桌面端个人学习与技术实践项目。音乐、账号及相关数据通过酷狗官方接口获取；请遵守平台规则，尊重音乐版权。

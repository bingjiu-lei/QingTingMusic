# 晴听音乐 v1.2.0

## 新增

- 私人 FM“不喜欢”。

## 优化

- 播放音质的菜单 UI 以及切换后实时更新播放。
- 音量播放调节本地持久化存储。
- 全局滚动条样式和交互。
- 设置页等界面的视觉统一。

## 修复

- 修复歌单缓存未及时刷新的问题。
- 修复主题切换后每日推荐日期框颜色未实时更新的问题。

## 下载与安装

- 文件：`QingTingMusic-Setup-v1.2.0-x64.exe`
- 系统：Windows 10 / 11（64 位）
- 大小：32.79 MB（34,414,103 字节）
- SHA-256：`B33AD70BA9FA65E0D70F3B1D51F2DBB934425E9E49D25CE035B61431C628BEEE`

直接运行安装包即可覆盖旧版本。

覆盖升级会保留登录信息、设置、缓存和播放记录。

安装包暂未进行数字签名。如果 Windows SmartScreen 提示未知发布者，请确认下载来源后点击“更多信息”→“仍要运行”。

完整卸载会删除程序、缓存、账号会话和其他晴听音乐用户数据。

## 已知限制

- 音质选项根据歌曲实际资源、账号权限和版权情况显示。
- 部分歌曲可能只有标准音质。
- 付费歌曲或无版权歌曲可能无法播放。
- 云盘歌曲默认只显示云盘音质；云盘歌曲关联在线资源时，才会显示其他可用音质。

## 项目说明

晴听音乐是使用 Flutter 开发的 Windows 桌面端个人学习与技术实践项目。

音乐、账号及相关数据通过酷狗官方接口获取。请遵守平台规则，尊重音乐版权，仅用于个人学习和技术研究。

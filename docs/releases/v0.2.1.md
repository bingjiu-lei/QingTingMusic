# 晴听音乐 v0.2.1

这是一个播放稳定性修复版本，主要解决部分 Windows 电脑中歌曲始终停留在 `00:00`、本地 MP3 提示没有访问权限的问题。

## 本次更新

- Windows 播放后端由系统媒体组件切换为独立的 `libmpv` 引擎。
- 不再依赖 Windows Media Foundation，即使系统自带媒体播放器异常，也可以正常播放歌曲。
- 在线歌曲改为直接通过 URL 播放，点击后无需等待缓存文件写入。
- 音频缓存改为后台静默保存，缓存失败不会中断当前播放。
- 缓存文件使用新的版本标识，避免继续读取旧版本留下的异常权限文件。
- 保留自动下一首、播放进度、暂停、切歌和最近播放等现有功能。

## 下载与安装

下载并运行：

```text
QingTingMusic-Setup-v0.2.1-x64.exe
```

支持 Windows 10 和 Windows 11 64 位系统。

如果已经安装旧版本，可以直接运行新安装包覆盖升级，无需提前卸载。

> 安装包暂未进行数字签名。如果 Windows SmartScreen 显示提示，可以点击“更多信息”，再选择“仍要运行”。

## 升级与卸载

- 覆盖升级会保留登录信息、设置和本地缓存。
- 完整卸载会删除程序和晴听音乐用户数据。
- 本版本会自动使用新的音频缓存文件，不需要手动清理旧缓存。

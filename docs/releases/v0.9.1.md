# 晴听音乐 v0.9.1

## 主要更新

- **歌手写真模式**：播放页可在专辑封面和歌手写真之间切换；写真选择会跨歌曲保持，横图、竖图和自带黑边的图片都会自然铺满窗口。
- **高音质选择补齐**：支持标准、HQ、无损和 Hi-Res，并在目标音质不可用时按顺序降级，优先保证能够播放。
- **Windows 任务栏控制**：悬浮任务栏图标即可上一首、播放/暂停和下一首，不必先切回软件。
- **封面取色主题**：可让当前封面的代表色驱动全局主题，切歌时自动更新界面氛围。

## 详细更新

### 播放与队列

- 同时监听播放器完成状态、末尾停滞和零时长元数据，减少歌曲停在结尾不切换的情况。
- 自动切歌时跳过无版权、需付费或解析失败的歌曲，不让整条队列被一首歌卡住。
- 修复歌曲完成后点击进度条无法恢复播放的问题。
- 补齐接口中的歌曲时长字段，每日推荐、私人 FM 和播放队列不再统一显示 `00:00`。
- 扩展播放地址候选解析，兼容更多官方接口返回结构。

### 歌词与播放页

- 增加歌手写真模式，隐藏专辑封面后让歌词居中显示。
- 写真模式不再给整张图片蒙白层；清晰前景配合柔化延展背景，减少横竖比例和源图片黑边造成的空白。
- 修复写真歌词黑白两层错位，看起来像重复文字的问题。
- 写真开关会在切歌和重新打开播放页后保持。
- 重排播放页控制胶囊，让上一首、播放和下一首稳定居中，并收紧左右留白。
- 支持歌词翻译与音译切换，精确时间歌词按字推进。
- 修复桌面歌词首次刷新时的 Windows 原生类型崩溃，并限制重复刷新，降低主窗口卡顿风险。

### 界面与交互

- 歌曲列表左上角改为与序号列对齐的轻量播放全部按钮。
- 推荐页播放按钮统一为轻量常驻底色；每日推荐详情入口改为箭头。
- 优化歌曲列表、搜索结果、设置页面和用户区的底部对齐与边缘过渡。
- 增加更顺滑的鼠标滚轮滚动，减少长列表一顿一顿的阻塞感。
- 歌单、专辑和页面切换减少不必要重绘，打开与返回更连贯。
- 播放栏、播放页、音量浮层和音质菜单重新对齐，统一按钮密度与交互状态。

## 下载与安装

下载并运行：

```text
QingTingMusic-Setup-v0.9.1-x64.exe
```

支持 Windows 10 和 Windows 11 64 位系统。

已经安装旧版本时，直接运行新安装包即可覆盖升级，无需提前卸载。

> 安装包暂未进行数字签名。如果 Windows SmartScreen 显示提示，请点击“更多信息”，再选择“仍要运行”。

## 升级与卸载

- 安装器继续使用固定 AppId，覆盖升级会保留登录信息、设置、本地缓存和播放记录。
- 完整卸载会删除程序和 `D:\QingTingMusic\userdata` 中的晴听音乐用户数据。
- 如需保留本地内容，请在完整卸载前自行备份用户数据目录。

## 已知限制

- 每日推荐、私人 FM、搜索、写真、歌词和在线播放依赖网络与酷狗登录状态。
- Hi-Res、无损及部分歌曲受账号、版权、地区和资源状态限制；不可用时会自动尝试较低音质。
- 部分歌曲可能没有写真、翻译或逐字时间轴。
- 安装包尚未进行数字签名。
- 当前仅维护 Windows 桌面版本。

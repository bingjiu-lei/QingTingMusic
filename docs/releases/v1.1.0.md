# 晴听音乐 v1.1.0

## 更新内容

- 优化桌面歌词窗口。
  - 支持锁定歌词窗口。
  - 支持调整歌词字号。
- 新增侧边栏展开状态设置，可在设置中保持展开或收起状态。
- 优化随机播放。
  - 随机模式下点击“播放全部”会随机选择一首歌曲。
  - 随机模式下点击指定歌曲后会准确播放所选歌曲。
  - 优化随机播放的上一首、下一首历史记录。
- 新增歌曲列表动态播放图标，更直观地显示当前播放歌曲。
- 新增日间、夜间模式切换过渡动画。
- 统一全局按钮、图标按钮、弹窗、输入框和轻提示的视觉与交互规范。
- 优化歌单、专辑详情页、搜索页和播放条布局。
- 优化“播放全部”按钮位置及歌曲列表操作按钮间距。
- 优化添加歌曲到歌单后的操作反馈。

## 问题修复

- 修复专辑或歌单取消收藏后无法再次收藏的问题。
- 修复自建歌单自定义封面判断不准确的问题。
- 修复自建歌单首曲变化后封面不能及时同步的问题。
- 优化快速切歌响应，确保最新一次切歌操作优先生效。

## 下载与安装

- 文件：`QingTingMusic-Setup-v1.1.0-x64.exe`
- 系统：Windows 10 / 11（64 位）
- 大小：34,450,657 字节（32.85 MiB）
- SHA-256：`F8547C06B72C087F1BC83AF61A9D6CA26FC9180DED2ED6FC3724681EAE2846B1`

直接运行安装包即可覆盖旧版本。覆盖升级会保留登录信息、设置、缓存和播放记录。

安装包暂未进行数字签名。若 Windows SmartScreen 提示未知发布者，请确认下载来源后点击“更多信息”→“仍要运行”。

完整卸载会删除程序、缓存、账号会话和其他晴听音乐用户数据。

## 项目说明

晴听音乐是使用 Flutter 开发的 Windows 桌面端个人学习与技术实践项目。音乐、账号及相关数据通过酷狗官方接口获取；请遵守平台规则，尊重音乐版权，仅用于个人学习和技术研究。

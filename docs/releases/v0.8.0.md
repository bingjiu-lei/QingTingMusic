# 晴听音乐 v0.8.0

这一版新增每日推荐和私人 FM，同时继续优化搜索与播放体验，让推荐、找歌和连续播放更自然。

## 本次更新

- 新增“推荐”入口，每日推荐和私人 FM 集中在同一页面。
- 每日推荐接入真实酷狗接口，点击可查看当天完整歌曲列表，也可以直接播放。
- 私人 FM 支持红心、小众、速览频道，以及口味、风格、探索偏好；切换后会重新加载歌曲。
- FM 会在当前歌曲接近播完时自动补充下一批歌曲，不会只循环最初的五首。
- 私人 FM 固定使用顺序播放；离开 FM 后会恢复原先的播放模式，避免随机播放打乱电台顺序。
- 修复每日推荐和私人 FM 播放队列时长显示为 `00:00` 的问题。
- 修复私人 FM 歌曲专辑显示为未知、专辑入口不可点击的问题。
- 优化搜索页空状态、最近搜索、联想搜索与清除交互，整体更轻量。
- 优化歌曲列表滚动、播放页打开和关闭的流畅度。
- 随机播放会记录真实听歌路径，快速切歌后“上一首”可以返回刚才实际听过的歌曲。
- 新增播放音质选择，可在播放栏和播放页查看并切换可用音质。

## 下载与安装

下载并运行：

```text
QingTingMusic-Setup-v0.8.0-x64.exe
```

支持 Windows 10 和 Windows 11 64 位系统。

如果已经安装旧版本，可以直接运行新安装包覆盖升级，无需提前卸载。

> 安装包暂未进行数字签名。如果 Windows SmartScreen 显示提示，可以点击“更多信息”，再选择“仍要运行”。

## 升级与卸载

- 覆盖升级会保留登录信息、设置、本地缓存和播放记录。
- 完整卸载会删除程序和 `D:\QingTingMusic\userdata` 中的晴听音乐用户数据。
- 如需保留本地内容，请在完整卸载前自行备份用户数据目录。

## 已知限制

- 每日推荐、私人 FM、音乐搜索和在线播放依赖网络与酷狗登录状态。
- 受版权、会员或地区限制的歌曲可能无法播放。
- 安装包尚未进行数字签名。
- 当前仅维护 Windows 桌面版本。

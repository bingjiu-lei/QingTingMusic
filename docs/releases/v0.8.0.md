## 本次更新

### 每日推荐与私人 FM

- 新增“推荐”页面：每日推荐与私人 FM 以紧凑入口并列展示，不再挤占主列表。
- 每日推荐使用真实酷狗接口获取当天歌曲；点击卡片可查看完整列表，播放按钮可直接开始播放。
- 私人 FM 接入真实接口，提供红心、小众、速览频道，以及口味、风格、探索偏好；每次切换都会重新请求歌曲。
- FM 每批歌曲播放至低水位时会自动续取下一批，不会反复循环最初的五首歌。
- FM 播放期间固定顺序播放，离开 FM 后恢复原来的播放模式，避免随机模式打乱电台顺序。
- 补齐推荐歌曲的真实时长、FM 嵌套专辑名称与专辑 ID，播放队列不再显示 `00:00`，可用专辑可正常进入详情。

### 搜索与播放体验

- 优化搜索页的空状态、最近搜索、联想搜索布局和清除交互，减少管理系统式的密集感。
- 歌曲列表悬浮保持普通鼠标指针，列表滚动、播放页打开与关闭的过渡更平滑。
- 默认列表显示更多歌曲，减少首次进入还需要滚动才能浏览内容的情况。
- 随机播放记录真实听歌路径，快速切歌后“上一首”可以返回实际听过的歌曲。
- 增加播放音质选择，播放栏与播放页可显示并切换可用音质。

## 安装与升级

1. 下载并运行 `QingTingMusic-Setup-v0.8.0-x64.exe`。
2. 旧版本可直接覆盖安装；安装目录默认优先使用 `D:\QingTingMusic`。
3. 覆盖升级会保留用户数据、登录状态、缓存和播放记录。
4. 完整卸载会删除程序及 `D:\QingTingMusic\userdata` 中的用户数据；如需保留本地内容，请先自行备份。

## 运行要求与说明

- 仅支持 Windows 10/11 64 位。
- 每日推荐、私人 FM、搜索与在线播放依赖网络和酷狗登录状态；受版权、会员与地区限制的歌曲可能无法播放。
- 安装包未进行代码签名；Windows SmartScreen 出现提示时，请确认安装包来源为本项目发布页后再选择继续。
- 晴听音乐使用酷狗官方接口获取音乐相关数据，不提供下载或绕过版权限制的能力。

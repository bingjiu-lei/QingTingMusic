# 晴听音乐 v0.9.2

## 主要更新

- **重做桌面歌词**：提升文字清晰度与逐字同步效果，增加悬浮播放控制和顺滑拖动，减少闪烁与卡顿。
- **写真模式更完整**：增加日间、夜间默认写真壁纸；写真会预加载并缓存，切歌与重新打开播放页不再白屏或反复播放过渡。
- **歌词加载更轻快**：用轻量动态提示替代突兀的转圈，降低切歌时的打断感。
- **翻译与音译更克制**：“译 / 音”开关仅在操作歌词时显示，鼠标离开或停止操作后自动隐藏，保持播放页干净。

## 下载与安装

下载并运行：

```text
QingTingMusic-Setup-v0.9.2-x64.exe
```

支持 Windows 10 和 Windows 11 64 位系统。已安装旧版本时，可直接覆盖升级。

> 安装包暂未进行数字签名。如 Windows SmartScreen 显示提示，请点击“更多信息”，再选择“仍要运行”。

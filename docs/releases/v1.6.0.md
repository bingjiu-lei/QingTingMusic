# 晴听音乐 v1.6.0

## 更新内容

- 新增扩展音源试听、收藏与转存（目前仅支持B站音源，设置页打开“其他音源”便可）。
  - 搜索与歌曲列表中支持检索并试听扩展音源内容。
  - 支持将扩展音源添加至本地收藏列表。
  - 支持将扩展音源快捷转存至个人云盘曲库。
- 优化 Windows 触屏设备手势兼容性。
  - 优化全局触控滑动与手势支持，触屏设备交互更流畅。

## 问题修复

- 优化音频播放稳定性，修复网络音频流加载超时挂起及切歌状态死锁问题。
- 修复 B 站音源因过期直链复用导致播放失败的问题，加固本地收藏持久化数据的脱敏与校验，并修复特殊字符 HTML 实体转义乱码。
- 修复合唱及多歌手歌曲中，点击歌手名称跳转主页时的 ID 错配与兜底错误。
- 修复应用切换至后台再切回前台时搜索框中文输入法候选框无法唤起、打字直出英文的问题，恢复原生输入法调度与 Shift 中英切换。

## 下载与安装

- 文件：`QingTingMusic-Setup-v1.6.0-x64.exe`
- 系统：Windows 10 / 11（64 位）
- 大小：26,354,145 字节（25.13 MB）
- SHA-256：`58F903F5817D88A08154D213FED9A63D004AACE4A34C050109284633BD38D549`

直接运行安装包即可覆盖旧版本。覆盖升级会保留登录信息、设置、缓存和播放记录。

安装包暂未进行数字签名。若 Windows SmartScreen 提示未知发布者，请确认下载来源后点击“更多信息”→“仍要运行”。

完整卸载会删除程序、缓存、账号会话和其他晴听音乐用户数据。

## 项目说明

晴听音乐是使用 Flutter 开发的 Windows 桌面端个人学习与技术实践项目。音乐、账号及相关数据通过酷狗官方接口获取；请遵守平台规则，尊重音乐版权，仅用于个人学习和技术研究。
